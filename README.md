# 單字學習遊戲 (Vocabulary Master)

一款專為高中生設計的 7000 單字學習行動應用程式。本作結合了寵物養成元素與遊戲化學習（Gamification），旨在降低背誦單字的枯燥感，提升長期記憶成效。

---

## 🛠 開發狀態
**當前版本：** `v0.0 (Development Build)`
> 本專案目前處於核心功能試驗階段。為了優化使用者體驗，部分商店功能暫時關閉，後續將在 3.0 版本引入網路搜尋與例句庫。

---

## 💡 設計核心與特色

### 1. 學習成效導向的「體力系統」
不同於一般遊戲為了營利設置體力，本作將體力上限設為 **20 點**（每日 04:00 自動恢復）：
*   **設計原因：** 根據認知負荷理論與個人學習經驗，每日背誦約 20 個新單字成效最佳。
*   **防疲勞機制：** 限制單日測驗題數，防止學生因過度刷題導致疲勞，確保每一題的品質。

### 2. 核心遊戲進程
透過「行動」獲得資源，回饋至寵物養成：
*   **多樣化測驗：** 提供「打工 (平衡型)」、「訓練 (經驗導向)」、「玩耍 (休閒導向)」三種模式。
*   **寵物進化：** 累積經驗值可觸發寵物進化，視覺化的成長感能轉化為學習動力。

### 3. 智慧單字庫管理
*   **熟悉度標記：** 學生可自定義單字熟悉程度，優化複習策略。
*   **清單功能：** 支持單字標記，方便快速過濾出不熟悉的詞彙進行強化練習。

---

## 🚀 技術亮點
*   **大容量資產管理：** 使用 **Git LFS (Large File Storage)** 管理高解析度字體與美術資源，優化版本控制效率。
*   **高品質文字渲染：** 整合 **TextMesh Pro** 與 **Noto Sans TC** 字型，解決中文字元過多導致的動態生成模糊問題，確保在各種螢幕解析度下皆有清晰的閱讀體驗。
*   **資料驅動程式設計：** 使用 CSV 檔案 管理 7000 單字庫與各難度所含單字。
